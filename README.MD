# Catálogo de Recursos Académicos

## Descripción
Este proyecto representa la estructura inicial de un sistema para registrar y consultar recursos académicos como libros, sitios web, videos, artículos y herramientas de software.

## Objetivo
Digitalizar y organizar recursos académicos en un catálogo estructurado que pueda crecer en futuras versiones.
