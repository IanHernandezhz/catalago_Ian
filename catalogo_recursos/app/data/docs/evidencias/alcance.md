# Alcance Futuro del Sistema
1. Búsqueda avanzada por categorías.
2. Filtrado por nivel educativo.
3. Exportación de listas en PDF/JSON.
4. Calificación de utilidad por usuarios.

# Criterios para clasificar recursos académicos

1. Tipo (libro, artículo, video, sitio web, software).  
2. Tema (matemáticas, programación, historia, etc.).  
3. Nivel (básico, intermedio, avanzado).  
4. Autor o fuente.  
5. Idioma del recurso (español, inglés, etc.).  
6. Año de publicación o actualización.
